**Tone for all feedback:** warm, grades 6–8, "you've got this." Never scold. Point back to the rule.

**Content rule:** items test only what M08 taught — the colors (recognition/meaning), the agreement *preview* (colors ending in -o switch to -a for a feminine noun; other colors don't change), the cardinal directions, the *está en / cerca de / lejos de* location chunks, and the place-name color links (Colorado = reddish, Amarillo = yellow). Any noun used for agreement (*casa, libro, silla, carro, gato, mesa*) is either a Module-2 known word or glossed in-item, so **no item secretly tests unrelated vocabulary memory** (gentle slope). *Está* is treated only as a fixed location phrase — the full ESTAR paradigm (taught in tandem with SER later) is **not** assessed here.

## Items

### Q1 — Color meaning (Multiple Choice)
**Prompt:** What color is **verde**?
- A) blue
- **B) green** ✅
- C) yellow
- D) red

*Feedback (correct):* "¡Sí! *verde* = green — a cousin of the English word 'verdant'."
*Feedback (incorrect):* "*verde* means green. (Think 'verdant', leafy green.)"

---

### Q2 — Color meaning (Multiple Choice)
**Prompt:** You see **rojo, blanco,** and **verde** on the Mexican flag. Which one is **red**?
- **A) rojo** ✅
- B) blanco
- C) verde

*Feedback (correct):* "¡Correcto! *rojo* = red. (*blanco* = white, *verde* = green.)"
*Feedback (incorrect):* "*rojo* is red. *blanco* = white and *verde* = green."

---

### Q3 — Agreement preview (Multiple Choice)
**Prompt:** "The red house": **la casa ___** (*casa* is feminine).
- A) rojo
- **B) roja** ✅

*Feedback (correct):* "¡Muy bien! *la casa* is feminine, so red switches to -a: *la casa roja*."
*Feedback (incorrect):* "*la casa* is feminine, so the color takes -a: *roja*. (Remember *amigo → amiga*.)"

---

### Q4 — Agreement preview (Multiple Choice)
**Prompt:** "The yellow book": **el libro ___** (*libro* is masculine).
- **A) amarillo** ✅
- B) amarilla

*Feedback (correct):* "¡Perfecto! *el libro* is masculine, so yellow stays -o: *el libro amarillo*."
*Feedback (incorrect):* "*el libro* is masculine, so the color keeps its -o ending: *amarillo*."

---

### Q5 — Colors that don't change (Multiple Choice)
**Prompt:** Which color does **NOT** change its ending for gender (one form works for everything)?
- A) blanco
- **B) azul** ✅
- C) negro

*Feedback (correct):* "¡Exacto! *azul* doesn't end in -o, so it never changes: *el carro azul, la silla azul*."
*Feedback (incorrect):* "Look for the color that doesn't end in -o. *azul* stays the same for every noun; *blanco* and *negro* switch to -a."

---

### Q6 — Directions (Multiple Choice)
**Prompt:** Which word means **north**?
- A) el sur
- **B) el norte** ✅
- C) el este

*Feedback (correct):* "¡Sí! *el norte* = north. (*el sur* = south, *el este* = east.)"
*Feedback (incorrect):* "*el norte* means north. (*el sur* = south, *el este* = east, *el oeste* = west.)"

---

### Q7 — Location chunk (Multiple Choice)
**Prompt:** You want to say a city is **near** the ocean. Which phrase do you use?
- A) lejos de (far from)
- **B) cerca de (near)** ✅
- C) al norte de (to the north of)

*Feedback (correct):* "¡Correcto! *cerca de* = 'near / close to'."
*Feedback (incorrect):* "*cerca de* means 'near'. (*lejos de* = far from.)"

---

### Q8 — Place-name color link (Multiple Choice)
**Prompt:** The US state name **COLORADO** comes from a Spanish word meaning:
- **A) reddish / red-colored** ✅
- B) snowy
- C) flowery

*Feedback (correct):* "¡Sí! *colorado* = 'reddish' — a cousin of *rojo*. Spanish explorers named the red, muddy Colorado River."
*Feedback (incorrect):* "*colorado* means 'reddish' (related to *rojo*). 'Snowy' is *Nevada*; 'flowery' is *Florida*."

## Alignment notes (for the builder / reviewer)

- **8 items, gate at 70% (6/8), unlimited attempts, highest score kept** — matches the brief's gentle-gate policy (§3) and "ambitious but relaxed."
- Coverage map: Q1–Q2 color meanings · Q3–Q4 agreement preview (fem -a, masc -o) · Q5 invariable colors · Q6 directions · Q7 location chunk · Q8 place-name color link. Every M08 objective is assessed.
- **Agreement is only *previewed*** — items give the noun's gender in the prompt so students apply the pattern, not recall each noun's gender from memory. Full agreement mastery comes later in the year.
- ***Está* is never conjugated or analyzed here** — Q-set uses it only as a set phrase; the ESTAR paradigm is taught in tandem with SER in a later module, per course design.
- M08 is **not** a graded culture-link checkpoint (those are M05, M15, M17), but Q8 reinforces the place-name link lightly, tying it to the *rojo/colorado* color the module taught.
- Correct-answer position is varied (B, A, B, A, B, B, B, A) to reduce pattern-guessing; the builder should also enable answer-choice shuffle.

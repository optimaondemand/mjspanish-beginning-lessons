# Module 3 — Quick Check (Tier-1 auto-graded gate quiz)

**Course:** M/J Spanish, Beginning (0708000) · Semester 1
**Module:** M03 — La clase (the classroom: objects, action-verb commands, gender)
**Assessment tier:** Tier 1 — auto-graded Canvas quiz (counts toward "Vocabulary & Grammar Quizzes" weight)
**Build location:** Canvas-native (New Quizzes). Not deployed to GitHub. Embed nothing; all items are Canvas question types.

> **Not a culture-link checkpoint.** The S1 graded culture-link checkpoints are M05, M15, M17. The loanword content here (cafetería / rancho / corral) is practice in the lessons; Q7 below is a single light loanword item for reinforcement, **not** a formal graded checkpoint.
>
> The brief's headline assessment for M03 is a **Tier-2 "classroom label" completion task** (label a photo of a room in Spanish, graded on submission + effort). This Quick Check is the separate short **Tier-1 module-gate quiz** every module carries.

## Settings

| Setting | Value |
|---|---|
| Question count | 7 (question order fixed; answer order may shuffle) |
| Points | 1 pt each = 7 pts total |
| **Gate threshold** | **70% (5 of 7) to advance to Module 4** |
| Attempts | **Unlimited** |
| Score kept | **Highest** |
| Feedback | Show correct answer + feedback comment **after each attempt** (immediate, encouraging) |
| Time limit | None |
| Shuffle | Shuffle answer choices ON; keep question order OFF |
| Mark as Done | Quiz completion is the module gate; lesson pages carry the Mark-as-Done banner |

**Tone for all feedback:** warm, grades 6–8, "you've got this." Never scold. Point back to the pattern.

**Content rule:** items test only what M03 taught — recognizing/responding to the eight classroom commands (received, not produced), the classroom object + people vocabulary, the -o/-a → el/la pattern applied to those words, and one light loanword item. No item tests command *production* (that is not taught this year yet). Spanish orthography throughout (á é í ó ú ñ ¿ ¡). Color-coding is not required in the quiz itself; it lives in the lessons.

## Items

### Q1 — Command recognition (Multiple Choice)
**Prompt:** Your teacher says **«Abra el libro.»** What should you do?
- **A) Open your book** ✅
- B) Stand up
- C) Look at the board
- D) Sit down

*Feedback (correct):* "¡Sí! *Abra el libro* = Open the book."
*Feedback (incorrect):* "*Abra el libro* means 'open the book.' Revisit the Lesson 3.02 command cards."

---

### Q2 — Command recognition (Multiple Choice)
**Prompt:** Which command tells you to **listen**?
- **A) Escuche** ✅
- B) Mire
- C) Escriba
- D) Siéntese

*Feedback (correct):* "¡Correcto! *Escuche* = Listen. *Mire* = look, *Escriba* = write, *Siéntese* = sit down."
*Feedback (incorrect):* "'Listen' is **Escuche**. *Mire* is look, *Escriba* is write, *Siéntese* is sit down."

---

### Q3 — Apply the gender rule (Multiple Choice)
**Prompt:** Choose the correct article: **_____ libro** (*libro* = book; it ends in **-o**).
- **A) el libro** ✅
- B) la libro

*Feedback (correct):* "¡Perfecto! *libro* ends in -o → **el libro**."
*Feedback (incorrect):* "*libro* ends in **-o**, so it is masculine: **el libro**."

---

### Q4 — Apply the gender rule (Multiple Choice)
**Prompt:** Choose the correct article: **_____ mochila** (*mochila* = backpack; it ends in **-a**).
- A) el mochila
- **B) la mochila** ✅

*Feedback (correct):* "¡Sí! *mochila* ends in -a → **la mochila**."
*Feedback (incorrect):* "*mochila* ends in **-a**, so it is feminine: **la mochila**."

---

### Q5 — Classroom vocabulary (Multiple Choice)
**Prompt:** In your classroom, the teacher writes on **la pizarra**. In English, that is the…
- A) door
- B) backpack
- **C) board / chalkboard** ✅
- D) chair

*Feedback (correct):* "¡Muy bien! *la pizarra* = the board."
*Feedback (incorrect):* "*la pizarra* is the board the teacher writes on. (*la puerta* = door, *la mochila* = backpack, *la silla* = chair.)"

---

### Q6 — People & natural gender (Multiple Choice)
**Prompt:** A male teacher is **el profesor**. What do you call a **female** teacher?
- **A) la profesora** ✅
- B) el profesora
- C) la profesor

*Feedback (correct):* "¡Exacto! For people, the ending matches: **la profesora** (a female teacher)."
*Feedback (incorrect):* "For a female teacher, both the ending and the article go feminine: **la profesora**."

---

### Q7 — Loanword / culture link (Multiple Choice) — *light, not a graded checkpoint*
**Prompt:** The everyday English word **cafeteria** came straight from which Spanish word?
- **A) cafetería** (a place that serves coffee and food) ✅
- B) corral (a pen for animals)
- C) pizarra (a board)

*Feedback (correct):* "¡Sí! English *cafeteria* is Spanish **cafetería** — one of the Spanish words hiding in your everyday English."
*Feedback (incorrect):* "It is **cafetería**. (*corral* = animal pen, *pizarra* = board.)"

## Alignment notes (for the builder / reviewer)

- **7 items, gate at 70% (5/7), unlimited attempts, highest score kept** — matches the brief's gentle-gate policy (§3) and the "ambitious but relaxed" principle.
- Coverage map: Q1–Q2 command recognition · Q3–Q4 gender rule applied to new vocab · Q5 object vocab · Q6 people / natural gender · Q7 light loanword link.
- **New grammar (commands) is tested only receptively** — recognizing what a command means / what to do, never producing a command form. **New vocabulary is tested on the known gender rule.** This honors "new grammar on known vocab; new vocab on known grammar — never both."
- Correct-answer position is varied across items (A, A, A, B, C, A, A) — where two-option items force A/B, distractor plausibility carries the load; shuffle is ON.
- This is **not** an S1 graded culture-link checkpoint (those are M05, M15, M17). Q7 is a single light loanword item for reinforcement.

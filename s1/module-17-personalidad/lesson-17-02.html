Lesson 17.02 · The core rule of the week
A describing word dresses to match the person
The same pattern you learned for nouns — -o and -a — comes back here for adjectives.
📖 TODAY'S FOCUS
When you describe a person with ser, many adjectives change their last letter to match a boy (-o) or a girl (-a).
We'll build every example on words you can already read — cognates — so the only new thing today is the ending. Then you'll sort adjectives by whether they change or not.
🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
change an -o adjective to -a when you describe a girl (generoso → generosa).
2
recognize the many adjectives (ending in -e) that stay the same for everyone (inteligente).
📚 PART 1 · ADJECTIVES THAT END IN -o / -a

Start with people, where it feels natural. Take generoso (generous). To describe a boy, keep the -o. To describe a girl, flip it to -a. The verb ser does the rest:

♂ Describing a boy → -o

  • Pablo es generoso.
  • Él es serio.
  • Marcos es tímido.

♀ Describing a girl → -a

  • Ana es generosa.
  • Ella es seria.
  • Lucia es tímida.

Same word, one letter different. This is the exact -o / -a pattern you already learned for nouns like amigo / amiga — now it's just riding on a describing word. Grammar teachers call this agreement, but the idea is friendlier than the name: the adjective just matches.

🧠 PART 2 · THE EASY ONES THAT NEVER CHANGE

Here's a gift: adjectives that end in -e don't change at all. Boy or girl, they stay exactly the same — and a lot of the best cognates are in this group.

Same for everyone — no ending to flip:
Pablo es inteligente. Ana es inteligente.
responsable paciente amable valiente

So the whole rule this week fits in one line: if it ends in -o, switch to -a for a girl; if it ends in -e, leave it alone.

🎮 PART 3 · SORT IT: DOES IT CHANGE?

Look at the last letter of each adjective and drag it to the right bucket. Ends in -o → it changes for a girl. Ends in -e → it stays the same. Correct drops lock in; wrong ones bounce back.

💡 Tip: you don't have to know the meaning to sort these — the ending tells you everything. "…o? → it can flip. …e? → it's frozen."
